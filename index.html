客服消息分流工具（本地研发原型）

目前不出售 API 订阅。此页面不是正在运营的服务，也不提供在线接口、自动发放密钥、配额、24 小时响应或订单系统。曾展示的价格和示例接口均未投入运营。

目前确实做到了什么？

在本地用关键词将中文客服消息分到退款、退货、投诉、发票、物流、发货等类别，并给出待人工核对的回复草稿。本地自动化测试覆盖五条样例；这不是实际客户成效或准确率统计。

工具不会查询真实订单、处理退款、发送消息或保障响应时间；不应用于未经人工审核的自动回复。当前程序只监听本机，不接受公网请求。
